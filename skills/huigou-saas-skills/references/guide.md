# 惠购 Saas 版 · 使用说明

为你的应用接入商品推广、订单返利和提现功能。想先体验小程序？按 [Demo README](https://github.com/shanjing-inc/huigou-saas-demo/blob/master/README.md) 启动。

## 能做什么

**用户登录 → 分享商品 → 生成推广链接 → 用户下单 → 订单结算 → 申请提现**

支持哪些商城和商品，以对接人为你开通的范围为准。

| 功能 | 说明 |
| --- | --- |
| 商品推广 | 解析分享内容、选择商品、查看详情、生成推广链接。 |
| 订单与钱包 | 查看订单、账单、余额和收益统计。生成链接后，用户还需下单才可能产生返利。 |
| 收款与提现 | 管理收款账号、申请提现、查询处理状态。系统记录处理结果，实际打款由约定的处理方完成。 |

预估返利还未到账，只有**可用余额**能申请提现。`pendingMoney`（待结算）包含未结算返利和在途提现本金；收益统计也不是钱包余额。

## 怎么接入

1. **拿到测试配置。** 向对接人取得 HTTPS 服务地址、App Key/Secret、组织 ID 和 Team ID。组织表示授权范围，Team 表示成员归属。
2. **让后端登录。** 先认证自己的用户，再用可信 OpenID、组织 ID、Team ID 调用 `login`，取得成员 Token（用户身份凭证）。密钥和 Token 只保存在可信后端，不放进小程序、网页或聊天。
3. **确认身份，再接业务。** 用 Token 调用 `getProfile`，核对成员和钱包；之后按需接商品、订单或提现功能。切换组织或 Team 时重新登录。

我们负责开通服务、商城能力并提供接口；你负责用户认证、页面和后端集成。Demo 使用固定测试 OpenID，正式接入需要替换为真实用户认证。

### 去哪里看接口文档

在**对接人提供的目标站点**后加以下路径：

- `/api/graphql/application`：应用接口，用 App Key、时间戳和签名鉴权。
- `/api/graphql/member`：成员接口，用 `Authorization: Bearer <Token>` 鉴权。

浏览器直接打开可进入 **Yoga GraphiQL**，在 Docs 中查看字段。GraphQL 文档插件也可向同一地址发送 POST JSON 自省查询（`__schema` / `__type`）导入文档。文档元数据可匿名读取，业务调用仍需鉴权和授权。

字段和参数以目标环境的 Schema（接口定义）为准。开发时查阅 [签名与请求示例](requests.md)；商品联调可用 [测试商品链接](test-materials.md)。

## 提现时注意什么

- Demo 登录测试身份后即可管理账号和申请提现，无需额外开关；仅用于获授权的专用隔离测试环境。
- 账号号码、类型或开户行变了，要新建账号再删除旧账号。首次登记会设为默认，后续提现所用账号会自动成为默认。
- 修改账号时留空表示不改；清空证件号需明确勾选。列表仅显示脱敏账号资料。
- Demo 提现金额至少 1 元，最多两位小数。提交成功会占用可用余额，处理进度看提现记录。
- 提交超时或结果不明时，先查记录，避免重复提现。

联调问题请向对接人提供接口名、时间和脱敏错误码，不发送密钥、完整 Token 或收款资料。
