# 惠购 Saas 版 · 小程序联调 Demo

## 项目介绍
本项目维护了惠购 Saas 版小程序的联调 Demo 作为参考，集成了 skill 用于接入 saas 业务接口。

具体业务接入请在本地打开 [使用说明](使用说明.html)，建议参考 AI 辅助接入模块引入 skill 进行辅助开发。

demo 相关介绍请继续阅读下文。

## 代码与数据流

| 位置 | 作用 |
| --- | --- |
| `miniprogram/pages/index/` | 连接测试身份、解析与选择候选、读取商品详情、转链、查看资金记录。 |
| `backend/server.mjs`、`backend/http.mjs` | 仅监听 `127.0.0.1` 的 Node HTTP 服务；仅开放固定 `/api/*` 路由。 |
| `backend/core.mjs`、`backend/queries.mjs` | 固定测试身份登录、签名、会话内存、输入校验和允许调用的 GraphQL 操作。 |
| `tests/` | 模拟上游的协议及小程序行为测试；不证明真实环境联通。 |

小程序只向本机后端请求。后端用私有 App Key/Secret 和隔离测试 OpenID 调用 application GraphQL `login`；成员 JWT 只保留在后端内存，页面持有随机会话 ID。后续 member GraphQL 请求通过该 JWT 访问；后端重启或会话失效后须重新连接。

钱包页先以成员 JWT 刷新 `getProfile`（可用余额、待结算、提现中及累计已提现），再由后端以应用签名调用 `listRevenueStatistic` 获取该成员按日（近 30 日）、月或年（近 366 日）的新增预估/已结算订单返利，并分页展示有数据的时段。成员 ID 来自本次登录结果，页面只能指定周期和页码；统计额不是钱包余额。现有接口没有自购、带货、邀请、任务四类拆分，页面不会伪造。收款账号列表仅下发脱敏姓名/账号，证件号及银行扩展信息不返回小程序。

解析分享内容得到候选后，页面最多并发两条 `getPromotionItem` 查询，逐步补齐真实图片、价格、券、可估算返利和店铺；上游失败时仍可选候选。商品详情优先按解析出的 `itemId` 查询，转链仍使用候选的 `itemUrl`。上游没有的字段不补造；返利状态为 `-1` 时不展示占位金额。订单列表从 `listOrders` 读取商品明细和订单/结算时间；商品与实付缺失时只展示已有的计佣金额，待结算与已结清返利分别标识，无效返利不显示金额。提现成功会占用可用余额，发起后刷新余额/默认账号；处理方审核、打款不在 Demo 内。

## 前提与安全

- Node.js >= 20.11；微信开发者工具模拟器；一套**专用隔离测试环境**、获授权的 App Key/Secret、organizationId、teamId、**隔离测试成员 OpenID**，以及已开通联盟的有效测试物料。不要使用生产客户账号、生产凭证或客户真实订单。联调目标服务须提供 HTTPS 地址。
- `.env` 只能存在于本机；不提交、不截图、不放日志。小程序仅保存内存中的随机后端会话 ID；真正的成员 JWT 仅在后端内存。后端重启后会话失效。
- 不调用 `wx.login` 或 `code2Session`。固定测试 OpenID 只用于隔离 Demo；**正式接入必须由合作方可信登录服务认证用户并提供 OpenID**，不能将此固定身份机制带入生产。
- 这个本机后端未提供面向公网的用户认证或设备鉴权；只允许在受信任开发机运行，不端口转发、不绑定公网、不部署成共享测试服务。
- 资金写接口无额外开关。**运行前确认服务、成员及余额均属已获授权的专用隔离测试环境**；HTTPS 与 `/api/status` 的 `configured: true` 均不代表环境隔离。不要将此 Demo 接入生产或共享环境。

## 启动与最短操作链

1. 将 `.env.example` 复制成不提交的 `.env`，仅在本机填写测试值。`DEMO_API_BASE_URL` 填对接人提供的测试服务 HTTPS 站点根地址（如 `https://test.example.com`）。后端会分别调用 `/api/graphql/application` 和 `/api/graphql/member`。默认端口为 8787；更改 `DEMO_PORT` 时须同步修改 `miniprogram/pages/index/index.js` 的 `BASE`。
2. 在仓库根目录运行 `pnpm backend`（已有的 `pnpm dev` 也可用）。检查 `http://127.0.0.1:8787/api/status` 的 `configured: true`；它**仅表示私有配置格式有效**，不是接口联通结果。若小程序已先打开、后端稍后才启动，在页面点击「重新检测本机后端」；修改 `.env` 或更新后端代码后须先在原终端 `Ctrl+C` 停止旧进程，再运行 `pnpm backend` 并重新连接。新版状态响应应包含 `supportsAccountManagement: true`；缺少该字段说明 8787 端口仍由旧版进程提供服务。
3. 微信开发者工具中导入仓库根目录。`project.config.json` 的 AppID 是本机可用的测试号，其他机器需替换为自己的测试 AppID。仅在**本地**设置 `project.private.config.json` 的 `setting.urlCheck: false`，允许模拟器访问 `http://127.0.0.1:8787`；该文件已忽略，严禁上传此开发期放宽配置。真机与体验版不在验收范围。
4. 点击「连接测试环境」验证 `login → getProfile`；粘贴**有效测试物料**解析，明确选择候选，按需查询详情，然后生成真实转链。订单、账单、提现标签直接查询真实测试环境（含空列表）并按需加载下一页。钱包页显示实际成员余额及按日/月/年的收益统计。
5. 钱包的「管理收款账号」可查看脱敏账号，也可登记支付宝、微信 OpenID 或银行卡账号，修改姓名/证件号或删除登记。账号号码、类型和开户行不能原地修改，需登记新账号再删除旧账号。首次登记自动成为默认；申请提现时选择收款账号、输入不低于 1 元且最多两位小数的金额，在确认弹窗复核后提交；成功会占用可用余额并更新默认账号，请查看提现记录确认处理状态。遇到超时或刷新失败，**先查看提现记录，不要重复提交**。
6. 退出：关闭开发者工具项目窗口；在运行后端的终端按 `Ctrl+C`。会话仅保存在后端内存，退出即清除。

## 协议边界

- 应用签名：`x-app-key`、秒级 `x-timestamp`、`x-signature`；签名为 GraphQL variables 中非空字段按 key 升序拼接 `key=value` 并追加 Secret 后的 **MD5 小写十六进制**。`login` 的 OpenID/organizationId/teamId 来自后端私有配置，客户端无法覆盖。
- 成员请求仅走 `Authorization: Bearer <JWT>`，限定为 `getProfile`、`parsePromotionMaterial`、按需 `getPromotionItem`、`createPromotionLink`、`listOrders`、`listBills`、`listWithdrawals`、`listWithdrawalAccounts` 和账号增删改及 `requestWithdrawal`；写操作仍须有效成员会话。钱包统计使用应用签名调用 `listRevenueStatistic`，成员 ID 固定由后端会话确认，客户端不能选择其他成员或任意日期。客户端和后端均不支持任意 GraphQL 查询。
- 接口字段与提现状态以实际联调目标环境的 application/member GraphQL Schema 为准；如与 Demo 不一致，请联系对接人确认。本 Demo **不预设**尚未上线的转链入参变更或免审核提现流程。
- 上游错误只对外返回安全的错误码/提示，不透传原始报错、Secret、JWT 或完整客户信息；账号列表仅返回脱敏账号/姓名，证件号和银行扩展信息不下发，提现不请求账号快照。错误凭证返回 `LOGIN_FAILED`，成员 Token 失效返回 `SESSION_EXPIRED` 并清空会话。资金写请求结果不明时返回 `UNCERTAIN`，须查询提现记录，切勿直接重试。

## 离线验证

`pnpm test`（或 `node --test tests/*.test.mjs`）使用本地模拟 GraphQL 响应，**只验证请求协议和页面所需字段，不证明真实联调或真实提现成功**。真实转链及资金操作验收需另行提供合法隔离测试凭证、资金及可用物料；没有时必须如实标记未完成。

## 联调验收

1. 从隔离环境的授权负责人取得测试服务地址、应用凭证、组织/Team ID、专用测试 OpenID 和已开通联盟的物料；按[启动步骤](#启动与最短操作链)创建本机 `.env`。不要将凭证、成员 JWT、私有响应或会话 ID 放入仓库、文档、截图、议题或命令日志。先运行 `pnpm test`，再在模拟器连接测试环境，核对成员资料是否对应授权身份；`/api/status` 的 `configured: true` 不证明上游可用。
2. 在联调目标依次核对 `login → getProfile → parsePromotionMaterial → getPromotionItem`：粘贴授权物料、选择候选、查看真实图片和价格。商品上游暂不可用时保留错误提示，不用假图或硬编码价格绕过。**确认专用隔离联盟账号及测试物料后**才调用 `createPromotionLink`；核对返回的落地链接/口令，转链不代表已下单或产生返利。
3. 检查订单、账单、提现列表的真实返回，包括空列表及分页；不要生成假记录。记录每项的测试环境、时间、结果与失败原因，向对接人反馈脱敏后的信息。
4. 资金联调另行核对账号列表脱敏显示、登记/修改/删除、选择账号申请提现，以及提交后的钱包余额与提现记录。编辑时留空表示不改，清空证件号须明确勾选；账号或开户行换绑须新建后删除旧号。不能手工设默认号，提现所用账号会自动成为默认。超时或刷新失败时先查询提现记录，避免重复提交。没有隔离测试余额或授权时，只验证离线模拟流程，不用真实客户余额替代。

## 常见边界

- 详情请求应传商品 ID 或详情页链接，不要把推广短链当作商品 ID。解析成功但商品上游暂不可用时，候选仍可选并显示“详情暂不可用”；排查上游前不要归因于页面样式。
- `SESSION_EXPIRED` 需重新连接；`UPSTREAM` 和 `NETWORK` 分别检查目标 GraphQL SDL/服务配置、网络与商品上游。后端不透传私有错误详情。
- 正式接入必须由合作方可信登录服务认证实际用户并替换固定 OpenID。此本机后端没有公网身份认证或设备鉴权，不可作为共享测试服务或生产服务部署。
- 目标环境 Schema 与 Demo 请求字段不一致时，记录字段差异和脱敏后的错误提示并联系对接人；离线模拟数据不能视为接口联通结果。
